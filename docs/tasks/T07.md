# T07 詳細分割（「もっと分ける」）

ブランチ: `task/T07-refine`（main から作成）
前提資料: `docs/SPEC.md` 4章・5章, `docs/ER.md`（SEPARATION_JOB の job_kind=refine・input_stem_id, STEM の parent_stem_id・is_residual, STEM_TYPE の refine_model_id）, `docs/research/R01-bpm-tempo-quality.md` D-3, T02 のパイプライン, T04 のジョブ, T05/T12 の画面, T13 のフォルダ構成

## 目的
分割済みの stem を、必要なときだけさらに細かく分ける。子の合計が親に一致するよう「残り（residual）」を必ず作る（SPEC 4章）。

## 対象（最初に作るもの）
| 親 | 子 | 方法 |
| --- | --- | --- |
| drums | kick, snare, toms, hihat, ride, crash ＋残り | `MDX23C-DrumSep-aufr33-jarredou.ckpt`（audio-separator） |
| vocals（または lead / backing） | male, female ＋残り | `bs_roformer_male_female_by_aufr33_sdr_7.2889.ckpt` |
| vocals（または lead / backing） | breath ＋残り | `aspiration_mel_band_roformer_sdr_18.9845.ckpt`（出力名は T01 で `breath` / `no_breath`） |
| other | 持続音（パッド）, 短い音（ヒット等）＋残り | HPSS（librosa、信号処理。GPU 不要）。R01 D-3 の設定（kernel 約1秒×約300Hz、margin=2）から始め、定数にして根拠をコメントに書く |

- 持続音・短い音の STEM_TYPE（例 `sustained`, `transient`。日本語表示名「持続音（パッド等）」「短い音（ヒット等）」）を seed に追加する（other の子、tier=detail、experimental=true）。
- 「残り」の STEM_TYPE をどうするか（T01 の持ち越し: 親の型を使い回すか、専用の型を作るか）を決めて報告する。推奨: 親ごとに `<親>_rest` のような専用の型を作り、表示名は「残り（ドラム）」など。
- DrumSep の出力名（kick, snare, toms, hh, ride, crash など）と STEM_TYPE の対応表を、モデルの yaml で確かめて作る（T02 と同じ方針。確かめられない名前は入れない）。
- モデルのダウンロード（DrumSep、男女、息）はユーザーの承認済みの範囲（SPEC に記載のモデル）。サイズを報告する。

## 作るもの
1. **refine ジョブ**: `POST /api/stems/{stem_id}/refine`（方法を指定。STEM_TYPE の refine_model_id または HPSS）。ワーカーで1件ずつ（GPU を使うものは T04 と同じ子プロセス）。進捗・キャンセル・失敗時の後始末は full ジョブと同じ。同じ stem に同じ方法の refine が既にあれば再実行しない（force で再実行）。
2. **子の保存**: 子 stem は親と同じジョブのフォルダの下（例 `drums/kick.flac` のようにサブフォルダ。T13 の構成に合わせて決め、報告）。配信用データ（Opus・peaks）も作る。子の合計＝親（float で 1e-5 以内。保存後は 24bit の量子化誤差の範囲）をパイプラインで保証し、テストで確かめる。
3. **画面「もっと分ける」**: プレイヤーの stem ボタンから、分けられる stem に「もっと分ける」を出す（方法を選ぶ）。実行中は進捗、終わったら子の stem ボタンが親の下にまとまって出る（T05 の親子ルール: 選択は葉だけで持つ、親ボタンは子をまとめて切り替え）。子を削除する（分ける前に戻す）操作も付ける。
4. **グループ・組み合わせプリセットとの関係**: 親が含まれるグループ・プリセットは子すべてを指す（T05 のルールのまま）。子を指定して保存した組み合わせを、子の無い曲で開いたときは親として扱う。
