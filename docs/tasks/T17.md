## 1. tailscale-serve.ps1 が PowerShell 5.1（cp932 のコンソール）で失敗する
- 現象（ユーザーの PC）: `.\scripts\tailscale-serve.ps1 start` が `[NG] ':' または '}' ではなく無効なオブジェクトが渡されました。 (5556)` で止まる。`tailscale status --json` の出力（UTF-8）を、コンソールの文字コード cp932 で読んだため、ユーザーの表示名（日本語）が `"蜑肴ｭｯ蝠・ｺ・,` のように化けて閉じの `"` が消え、ConvertFrom-Json が失敗している。監督役の環境（コンソールが UTF-8）では再現しない。
- 直し方: tailscale を呼ぶ前後で `[Console]::OutputEncoding` を UTF-8 に切り替えて元に戻す（`$OutputEncoding` も）、または tailscale の出力をバイト列で受けて UTF-8 で解釈する。JSON を読むのは必要な項目（DNSName、Funnel の状態など）だけにする。
- 確認: `chcp 932` の `powershell.exe`（5.1）で `status` / `start` / `stop` が通ること（start/stop は実際に serve を有効にして直後に止めてよい。最後は必ず止めた状態にし、`tailscale serve status` で確認。Funnel は絶対に使わない）。BOM 付き UTF-8・CRLF を保つ。
- `stemapp doctor` の Tailscale の確認（Python）も、表示名に日本語があっても正しく動くことを確かめる（subprocess の encoding）。
