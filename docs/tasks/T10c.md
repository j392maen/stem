# T10c 拍の手動補正と小節単位の操作

ブランチ: `task/T10c-beat-edit`（T10 をマージした後の main から作成）
前提資料: `docs/research/R01-bpm-tempo-quality.md`（B 章）, `docs/tasks/T10.md`, T10 の `src/stemapp/beats/`・`web/js/beats.js`・`waveform.js`・`player.js`, `docs/ER.md`（BEAT_GRID, BEAT_ANCHOR）

## 目的
自動で求めた拍がずれた・倍や半分に取られた・小節の頭が違う、というときに、ユーザーが画面で素早く直せるようにする。あわせて、拍の情報を使った DJ 的な操作（キューを拍に合わせる、小節単位のループ）を加える。

## データの持ち方
- 自動の結果（BEAT_GRID.beats_json / downbeats_json）は書き換えない。
- ユーザーが直した結果は BEAT_GRID に `edited_beats_json`, `edited_downbeats_json`, `edited_time_signature`（NULL なら自動の結果を使う）として持つ。画面と API は「有効な拍」（直した結果があればそれ、無ければ自動）を使う。
- 操作の履歴を BEAT_ANCHOR（T10 で作成済み。足りない列は足してよい）または別表に残し、**元に戻す**（少なくとも直前の1操作、できれば複数）と**自動に戻す**（全部取り消す）ができるようにする。
- 区間 BPM は今どおり「有効な拍」から毎回計算する（T10 の tempo.py を使う）。
- `docs/ER.md` を更新する。

## 補正の操作（プレイヤーの「拍の補正」パネル。普段は閉じておく）
1. **1小節目をここに**: 再生位置に最も近い拍を、小節の頭（1拍目）にする。拍の時刻は動かさず、小節の区切り（ダウンビート）を付け直す。以降は拍子どおりに区切る。区間ごとに拍子が違う場合はその区間だけでもよい（範囲の考え方は下の「範囲」）。
2. **×2 / ÷2**: 範囲の拍の数を倍（間に拍を足す）／半分（1つおきに間引く）にする。
3. **拍子**: 3・4・5・6・7 拍から選ぶ。
4. **ずらす**: 範囲の拍を ±10ms 単位（Shift で ±1ms）で前後に動かす。
5. **タップ**: ボタン（またはキー T）を拍に合わせて4回以上たたくと、その間隔と位置から一定テンポの拍を作り、範囲の拍を置き換える。たたいた時刻は再生中の曲の時刻で扱い、出力の遅延（AudioContext の outputLatency / baseLatency）を差し引く。
6. **キュー2点から**: 2つのキューと、その間の小節数を指定すると、その間を一定テンポの拍で置き換える（小節の頭はキューの位置）。
7. **範囲**: 既定は「再生位置を含む区間（T10 の segments）」。「曲全体」も選べる。ループが設定されていれば「ループ区間」も選べる。
8. 元に戻す（Ctrl+Z も）、自動に戻す（確認つき）。
- 直すと、波形の拍の線・小節線、BPM 表示がすぐに変わる。保存は API で即時。

## 拍を使う操作
- **キューを拍に合わせる**（スナップ）: 設定で ON/OFF（既定 ON）。キューを打つとき・キューを動かすとき、最も近い拍に合わせる。
- **小節単位のループ**: 再生位置の小節の頭から 1・2・4・8・16 小節のループを1操作で作る（ボタンと、キー操作の案を報告）。ループの長さを倍・半分にする操作。
- **テンポが変わる位置の印**: 概観波形の上に、区間の境目を小さな印で表示し、ポインタを合わせると前後の BPM を出す。

## API
- `GET /api/tracks/{id}/beats` に「有効な拍」と、直したかどうか（edited）、元に戻せるか（can_undo）を含める。
- 補正の操作を行う API（操作の種類と引数を受け取り、サーバー側で計算して保存する形を推奨。計算はテストしやすい純粋関数にする）。元に戻す・自動に戻す。
- 再解析（T10 の POST /api/tracks/{id}/beats）をしたときの、直した結果の扱いを決めて報告（例: 直した結果は残し、「自動に戻す」を押したときだけ新しい自動の結果を使う）。

## テスト

- API、移行。
- ブラウザテスト（Fake の解析器）: 補正パネルで ×2 → 小節線と BPM 表示が変わる → 元に戻す。タップで BPM が作られる（テスト用に時刻を差し込めるようにしてよい）。スナップ、小節ループ。スクリーンショット（PC・スマホ幅）。
