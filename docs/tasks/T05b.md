# T05b 再生画面の小改善（ユーザー確認の反映）

ブランチ: `task/T05b-player-tweaks`（main から作成）
前提資料: T05 の `src/stemapp/web/`、`docs/tasks/T05.md`

## 目的
ユーザーが実際の曲で確認した結果の要望のうち、すぐ直せるものを反映する。BPM・拍の線・速度変更は調査後に別タスクで行うので、ここでは触らない。

## 作るもの
1. **再生ボタンの見た目**: 今の「赤い丸」は録音ボタンと間違えやすい。一般的な再生アイコン（▶ / ❚❚）が主役になる形にし、ボタンの地を赤い丸にしない（例: 暗い地に明るい枠、アイコンは白か差し色の赤）。赤の差し色は使ってよいが、「赤い塗りつぶしの丸」は避ける。
2. **「0」キー**: 「全部（元の曲）」に切り替える。もう一度押すと、直前の組み合わせに戻る（切り替えの往復）。キー操作の説明表示にも追加する。
3. **stem の保存場所を開く**: プレイヤーに「保存フォルダを開く」ボタンを置く。
   - API `POST /api/jobs/{id}/open-folder`: サーバーの PC で、そのジョブの stem（master FLAC）のフォルダをエクスプローラーで開く（`explorer.exe` をフォルダのパスで起動。外部コマンドの起動は `stemapp.proc` の決まりに従う。ただしエクスプローラーはアプリ終了で道連れに閉じないよう、Job に入れない起動方法にする）。Windows 以外では 501。
   - このボタンは、ブラウザがサーバーと同じ PC から開いているとき（接続元が 127.0.0.1 / ::1）だけ表示・実行できる。それ以外（iPhone など）からの呼び出しは 403。
   - フォルダには stem が FLAC（24bit）で保存されていることを、ボタンの近くか title に日本語で書く。
   - 必要ならフォルダ内のファイル名は今のまま（`<stem code>.flac`）でよい（書き出し機能は T08）。
4. テスト: API（ローカルからは explorer の起動関数が呼ばれる＝差し替えて確認、ローカル以外は 403、存在しないジョブは 404、Windows 以外は 501）。ブラウザテスト: 0 キーの往復、再生ボタンが表示されること。スクリーンショットを撮り直す（PC・スマホ幅）。

## 完了条件
1. `uv run pytest -q`、`uv run pytest -q -m browser` が全件成功
2. `uv run ruff check` がエラーなし
3. スクリーンショット（PC・スマホ幅）を `data/cache/screens/` に撮り直す
4. ブランチ `task/T05b-player-tweaks` にコミット（main へのマージは監督役）

## 報告内容
変えたファイル、再生ボタンのデザインの説明、0 キーの動き、フォルダを開く仕組みと安全策、完了条件の結果、スクリーンショットのパス。
