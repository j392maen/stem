# T08 書き出し（個別・一括 ZIP・組み合わせのミックス）

ブランチ: `task/T08-export`（main から作成）
前提資料: `docs/SPEC.md`, `docs/ER.md`（EXPORT, EXPORT_ITEM）, T04 の API・ジョブ, T05 の画面, `docs/PLAN.md`

## 目的
分割した stem を、ユーザーが使いやすい形でファイルに書き出してダウンロードできるようにする（PC と iPhone の両方のブラウザから）。

## 作るもの
1. **書き出しの種類**（EXPORT.export_type）
   - `single`: stem 1つ
   - `all`: そのジョブの全 stem（葉の stem。親子がある場合は子。ユーザーが親だけにしたい場合の選択肢も付ける）を ZIP にまとめる
   - `mix`: 今の組み合わせ（選択中の stem、または組み合わせプリセット。gain_db を反映）を1つの音声に混ぜる
2. **形式**（EXPORT.format）: WAV（24bit）、FLAC（24bit）、MP3（320kbps、ffmpeg の libmp3lame）。ZIP の中身もこの3形式から選べる。
3. **元の音源は master の FLAC**（STEM_RENDITION purpose=master）。配信用の Opus は使わない。
4. **ファイル名**: `<曲名> - <stem の表示名>.<拡張子>`（mix は `<曲名> - <組み合わせ名 または 選んだ stem の表示名を「＋」でつないだもの>`、ZIP は `<曲名> - stems.zip`）。曲名は TRACK.title。ファイル名に使えない文字（`\ / : * ? " < > |`、制御文字）は飛ばし、末尾のピリオド・空白を除き、予約名（CON など）は末尾に `_`、長さは 100 文字まで。ダウンロード時の Content-Disposition は日本語名が化けないよう RFC 5987（filename*=UTF-8''...）で出す。
5. **音量の扱い**: stem には分割時の倍率（SEPARATION_JOB.output_gain_db）がかかっている。書き出しはそのままの音量で出す（戻すとクリップするため）。mix で合計が ±1 を超える場合は、クリップさせずに全体を同じ倍率で下げ、下げた量を EXPORT に記録して画面に出す（列を足してよい）。
6. **処理の流れ**: 書き出しはサーバー内のバックグラウンド（スレッドまたはワーカーのキュー。GPU は使わない。判断して報告）で行い、`POST /api/jobs/{id}/exports`（種類・形式・対象）→ export_id、`GET /api/exports/{id}`（状態・進捗・ファイル名・サイズ）、`GET /api/exports/{id}/download`（Range 対応）。外部コマンドは `stemapp.proc` の決まりで起動。
7. **保存場所と片付け**: `data/exports/<export_id>/`。作ってから 24 時間たったもの、または合計 2GB を超えた分は古い順に消す（設定で変更可）。曲・ジョブを削除したら関係する書き出しも消す。
8. **画面**: プレイヤーに「書き出し」メニュー（stem を1つ／全部を ZIP／今の組み合わせをミックス、形式の選択）。作成中は進捗、できたらダウンロード（ブラウザの保存）。iPhone の Safari/Chrome でも保存できる形にする（`<a download>` と、ダメな場合の案内）。デザインはユーザーの好み（暗い DJ ソフト風、差し色は赤系統で1〜3色）。
9. **CLI**: `stemapp export <job_id> --type single|all|mix --format wav|flac|mp3 [--stem code] [--preset 名前] -o <出力先フォルダ>`（出力先はユーザーが指定。data/exports を使わない）。

## テスト
- ファイル名の整形（日本語、使えない文字、予約名、長さ）、Content-Disposition。
- 各種類×各形式（`@pytest.mark.ffmpeg`）: 長さ・チャンネル・サンプルレート、mix の中身が選んだ stem の合計（gain_db 反映）と一致（WAV/FLAC で誤差 24bit 相当）、クリップ時の倍率。
- ZIP の中身、API（404・409・Range）、片付け（期限・容量）、曲・ジョブの削除で消える。
- ブラウザテスト（Fake）: 書き出しメニュー → 作成 → ダウンロード（テストではダウンロードの発生を確認）。スクリーンショット（PC・スマホ幅）。
