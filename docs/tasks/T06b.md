# T06b iPhone 向けの再生（消音モード・ロック中・メモリ・続きから再生）

ブランチ: `task/T06b-iphone-playback`（main から作成）
前提資料: `docs/SPEC.md` 7章, `docs/ER.md`（DEVICE, PLAYBACK_STATE）, `docs/USER_CHECKLIST.md` 3章・5章, T06a/T06b-0 の診断（`src/stemapp/web/js/iosexp.js`）, T05/T11/T11c の再生エンジン（`engine.js`・`tempo.js`・`player.js`）

## 実機の実験結果（2026-10-04、iPhone の Chrome、iOS 26.6.2）
| 方法 | 消音モード | ロック中 | ロック画面の曲名・操作 |
| --- | --- | --- | --- |
| A: `navigator.audioSession.type = "playback"` ＋ Web Audio | 鳴った | 鳴り続けた（音の時計も進んだ） | 出た |
| B: 無音の `<audio>` ＋ Web Audio | 鳴った | 止まった | 出た |
| C: Web Audio → `createMediaStreamDestination()` → `<audio>.srcObject` | 鳴った | 鳴り続けた | 出た |
| D: `<audio>` だけ | 鳴った | 鳴り続けた | 出た |
→ **今の Web Audio のエンジンに A を足せば、iPhone でも消音モード・ロック中に使える。A が無い端末では C で代わりにする。**

## 作るもの
1. **音声セッション（A と C）**
   - 再生を始めるとき（ユーザーの操作の中で）、`navigator.audioSession` があれば `type = "playback"` にする。
   - 無ければ、エンジンの最終出力を `createMediaStreamDestination()` に流し、`<audio>.srcObject` で鳴らす方式（C）に切り替える。C のときも、シーク・ループ・stem の切り替え・速度変更（T11/T11c）・拍の線との同期が今までどおり動くこと（C の経路で増える遅れがあれば測って位置計算に入れる）。
   - PC では今までどおり（どちらも使わない）でよいが、A があれば付けても害が無いか確かめる。どの方式で鳴らしているかを、設定画面かプレイヤーの小さな表示で確認できるようにする。
2. **ロック画面の表示と操作（Media Session）**
   - 曲名・アーティスト・アートワーク（アプリのアイコン）を設定。再生・一時停止・10 秒戻る／進む・シーク（seekto）のハンドラ。`setPositionState`（長さ・位置・速度）を再生中に更新する（速度変更の倍率も反映）。
   - 組み合わせプリセットを選んでいるときは、曲名の下にその名前を出す（例: アルバム欄）。
3. **iPhone では選んでいる stem だけ読み込む**（SPEC 7章）
   - スマホ（`pointer: coarse` かつ幅 640px 以下、または設定で選んだとき）では、選択中の葉 stem の音声だけを読み込んで鳴らす。stem を ON にしたときに未読み込みなら読み込んでから同じ曲時刻で鳴らし始める（読み込み中はボタンに小さな表示）。OFF にした stem の音声はしばらく（例: 2 分、または合計が上限を超えたら）残してから捨てる。
   - 同期の保ち方（後から読み込んだ stem を、鳴っている他の stem と同じ曲時刻に合わせて start する）を位置計算と同じ方法で行い、ずれを測って報告する。
   - メモリの目安（デコード後のサイズ）を画面のどこかに小さく出す（省メモリの判断材料）。
4. **続きから再生（PLAYBACK_STATE）**
   - 端末ごとの ID（localStorage）と名前（「iPhone」「PC」など。自動で付け、変更可）で DEVICE に登録する API。
   - 曲ごと・端末ごとに、再生位置・選択中の stem・組み合わせプリセット・分け方（ジョブ）・速度と方式を、一定間隔（例: 5 秒ごと、および一時停止・画面を離れるとき）で保存し、次に開いたときに戻す（「続きから再生」）。別の端末で最後に聴いていた位置も、プレイヤーで「PC で 1:23 まで聴いた」と出して選べるようにする。
   - `docs/ER.md` の DEVICE・PLAYBACK_STATE に合わせる（足りない列は足し、ER.md を更新）。
5. **通知は今回は作らない**（iPhone のブラウザでは Web Push が使えなかった。ホーム画面から開いた場合だけ使える可能性があるので、後の課題として PLAN に残す）。
