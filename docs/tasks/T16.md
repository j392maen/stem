# T16 CLI が cp932 で表示できない文字で落ちる

ブランチ: `task/T16-cli-encoding`（main から作成）

## 現象（監督役が 2026-10-03 に実データで確認）
`uv run stemapp migrate-folders --dry-run` を Windows のコンソール（文字コード cp932）で実行すると、曲名「春嵐 ⧸ 初音ミク」の `⧸`（U+29F8）を表示できず、rich の `legacy_windows_render` で `UnicodeEncodeError: 'cp932' codec can't encode character '\u29f8'` になって落ちる。`PYTHONUTF8=1` と `PYTHONIOENCODING=utf-8` を付ければ表示できる。
同じことは、曲名やファイル名を表示するすべての CLI（separate、import、export、beats、migrate-folders、doctor など）で起こりうる。ユーザーは PowerShell から CLI を使う。

## 作るもの
1. CLI の起動時に、標準出力・標準エラーを UTF-8（errors="replace"）に切り替える、または rich の Console を cp932 で表せない文字を置き換えて出す設定にする。PowerShell 5.1 の既定のコンソール（cp932）と Windows Terminal の両方で、日本語と `⧸` のような記号が文字化けせず（または安全な代替文字に置き換わって）落ちないこと。どちらの方法にしたか、日本語の表示がどう見えるかを報告。
2. `scripts/start.bat` と `scripts/setup.ps1` から起動したときも同じであること。
3. テスト: cp932 の出力先（`io.TextIOWrapper(..., encoding="cp932")` など）に `⧸`・絵文字・日本語を含む曲名の表を出しても例外にならないこと。

## 完了条件
1. `pytest -q`、`ruff check` が全件成功
2. 実機で、PowerShell（`powershell.exe`、既定のコンソール）から `uv run stemapp migrate-folders --dry-run` を実行して落ちないこと（実データでの dry-run は何も変えないので実行してよい。本実行はしない）。
3. ブランチ `task/T16-cli-encoding` にコミット（main へのマージは監督役）
